端云协同 架构概览

一个本地服务，把应用、云端 API 与本地小模型接到同一套路由上。
应用接入 Router，按策略选择云端或本地模型；底层共享脱敏、配置和观测能力。

一次请求，在第 3 步分叉；回退仍受原来的请求预算与隐私要求约束。

云端发送前的真实顺序

选定候选 → 准备目标协议载荷（含 ExtraBody） → 按策略本地识别与替换 → 注入凭据并发送 → 适配与还原响应。

本地执行失败只有在策略、预算和未提交输出等条件允许时才能回退。必需脱敏失败时阻断云端发送。
