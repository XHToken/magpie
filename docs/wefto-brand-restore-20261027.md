# Wefto 名称与 W 图标本地恢复

这是早期工作目录的排障记录。beta.6 发布候选基于最新 Wefto 主线，保留完整正式更名及其兼容迁移；继续修复本文描述的共享 favicon 覆盖问题。

## 原因

当前工作目录 `main` 停在 `1e2bf47e`，没有包含此前的 `3453ab8d`（Wefto 更名）提交；该提交存在于本地 Wefto 相关分支。此前从当前目录编译的本地模型更新仍嵌入 API-router 标题和品牌。

另有图标路由覆盖：服务启动时将共享 Magpie 的所有 SVG 图标加入 visualAssets，并优先于产品专属 `/icons/favicon.svg` 路由返回。于是，即使修改产品 favicon 文件，实际响应仍可能是喜鹊图标。

## 本次恢复

- 当前功能版本的浏览器标题、侧栏/顶部名称、关于页面、教程和用量文案使用 Wefto。简中和繁中分别显示 Wefto 织流、Wefto 織流。
- 采用原 Wefto 更名提交的 W 图标样式；产品 favicon 优先于上游共享资源，URL 使用新的 `wefto-w-20261027` 标记更新浏览器缓存。
- README 标题/介绍和项目启动提示恢复 Wefto 名称。
- 当前兼容的 `api-router.exe` 启动路径、数据目录、浏览器阅读进度、协议服务标识、认证头和宿主配置沿用现有接口。恢复品牌显示不迁移目录或重写宿主配置；已有宿主中的 API Router 名称仍指向原绑定。
- 当前 X2.6 Q4/Q8 目录与已批准的设备推荐/性能策略保留。
