# 端云协同 0.1.0-beta.14（草稿）

此版本尚未通过发布验收，供源码审阅与隔离验证。公开版本继续使用 beta.13。

- Windows 使用 DPAPI 保护逐条用户消息的识别结果，兼容的重复历史和零命中结果可在重启后复用。
- 按完整请求替换已知敏感值，检查最终出站正文；未知旧消息阻断并要求显式本地补处理。
- 管理页面提供逐批补处理、进度和取消，观察记录显示新增识别、历史复用和出站检查情况。
- 请求记录只显示供应商故障转移后的最终错误；成功请求不再显示中间失败为终态错误。

## 发布阻碍与限制

1. 删除源用户消息后，旧助手或工具回显的原值残留尚无可信宿主生命周期保护；不能宣称此路径已受保护。
2. 新的持久脱敏后端仅支持 Windows。Linux/macOS 的生产脱敏明确阻断，不能将交叉构建成功视为功能支持。
3. 部分初始化恢复、坏记录修复、密钥轮换和备份恢复工具尚未完成；应保留错误现场，禁止自动删库重建。
4. 全库和原生 race 的最终验收以随包 BUILD-INFO.json 和验证记录为准。未运行的检查不能视为通过。

草稿可包含 Windows x64、macOS Intel/Apple Silicon、Linux x64/ARM64 候选包。提供架构、归档成员、SHA256 校验和及准确源码信息。macOS 与 Linux ARM64 没有原生验证；未执行真实模型质量、付费云端请求、全部宿主编辑/删除及断电恢复验收。Windows/macOS 包未签名，macOS 未公证。

完整范围见[历史脱敏实施记录](../redaction-history-implementation-20261030.md)。在解决发布阻碍前，不将此草稿标为公开版本。
