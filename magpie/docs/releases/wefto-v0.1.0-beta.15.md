# 端云协同 0.1.0-beta.15（预发布）

本版本新增 Spark-X2.6 1.7B 两款本地模型，并修复下载源切换时丢失断点的问题。

- 新增 **Spark-X2.6-1.7B-Q4_K_M**（约 1.77 GB）和 **Spark-X2.6-1.7B-Q8_0**（约 1.82 GB）。使用固定官方版本、字节数和 SHA256；先尝试 HF-Mirror，再尝试 Hugging Face 官方源。
- 1.7B 独立评估内存、CPU、运行后端与安装磁盘预算。自动推荐参考值为 8 GiB 总内存、5 GiB 可用内存、4 逻辑线程；明确手动试用的可用内存下限为 4 GiB。实际加载、健康与能力检查仍须通过。
- 本地模型下载页、已安装列表、供应商入口、Loomy/WorkBuddy 模型选择、路由组和请求记录显示完整档位及量化名称。修复入口定位、窄屏换行及路由组操作栏重叠，补齐五种语言。
- 模型预览保留所选展示项；切换运行模型仍需操作模型开关。已安装但关闭的模型显示“已安装”，未安装模型不进入可用模型列表。
- 修复主下载源限流、备用源连接失败时提前删除原断点的问题。备用源返回可用完整响应后才替换旧文件；后续重试保留原偏移和验证器，最终仍校验完整长度与 SHA256。
- 规范化 POSIX/非法浏览器 locale，避免日期格式化异常把健康服务误报为断连。

本版本仍为预发布。**新增 1.7B 的真实对话、多轮工具调用、64K 性能及识别质量尚未完成实机验收**；目录和交互测试通过不代表这些能力已通过。镜像源可能限流，官方源也可能出现连接超时或低速，下载失败可重试。真实模型权重和推理引擎通过管理页面另行下载，不包含在应用安装包内。

沿用 beta.14 的已知限制：macOS 原生系统密钥与推理验收尚缺，可信宿主编辑/删除、删除原文后的旧回显保护及完整恢复管理尚未完成。Linux 持久脱敏需要可用且已解锁的用户会话 Secret Service，macOS 需要可用且已解锁的默认 Keychain。Windows/macOS 包未签名，macOS 未公证。

附件包含 Windows x64、Linux x64/ARM64、macOS Intel/Apple Silicon 共五个平台归档、五份 manifest、Windows 安装脚本、Unix 说明、BUILD-INFO.json 和 SHA256SUMS，共 14 项。实际构建源码、平台验证结果及未运行项目以 BUILD-INFO.json 为准。
