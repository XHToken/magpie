# 端云协同 0.1.0-beta.7 · 界面对齐与 Loomy 重连

本预览版将管理页面、教程、宿主生成标签与使用说明统一显示为“端云协同”。发布标签、`wefto` 命令、配置目录、服务身份和旧安装兼容机制继续使用现有技术标识。

- 修复 Loomy 切换到原生模型后无法重新接入的问题：明确重新连接会在验证现有供应商后选择请求的路由目标，保留独立小模型、用户扩展与最初的恢复基线；供应商冲突或 Profile 保存失败会停止并回滚。
- 升级既有 API Router / Wefto 生成标签，同时保留供应商 ID、用户模型别名和离线恢复能力。
- 对齐 Loomy、WorkBuddy 模型选择弹窗的名称、标签、排序列与折叠标题，改善窄窗口边界与长模型名换行。
- 将 GPU 回退提示放进推理后端状态行，避免与下一行重叠。
- 更新五语言界面与端云一体 skill，沿用 beta.6 的 Spark X2.6 Q4_K_M / Q8_0、设备资源推荐、校验下载和冷加载准入。

提供 Windows x64、macOS arm64/x64、Linux arm64/x64 便携包、逐文件 manifest、独立 Windows 安装器与 SHA256SUMS。升级前结束当前请求并停止旧服务，按升级指引切换程序，保留配置、凭据、模型与宿主恢复记录。

验证记录与固定源码见随包 BUILD-INFO.json。macOS 与 Linux arm64 包为交叉编译产物；未在对应原生平台运行。安装包未签名，macOS 未公证。本次不包含真实模型权重推理、业务质量校准或付费云端调用验收。
