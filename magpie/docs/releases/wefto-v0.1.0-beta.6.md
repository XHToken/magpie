# Wefto 0.1.0-beta.6 · Spark X2.6 与设备推荐

本预览版将端侧模型目录更新为 **Spark-X2.6-4B-Q4_K_M** 和 **Spark-X2.6-4B-Q8_0**，并让管理页面与一键配置 skill 使用同一份设备建议。

- 两款量化使用各自固定版本、大小与 SHA256，沿用可恢复下载、完整性校验和单进程生命周期；停止提供 X2.5 的选择、下载与安装入口。旧权重缓存保留，旧 X2.5 选择不会静默授权另一款模型。
- 已知低配设备可直接提示不建议下载；临时空闲内存/磁盘不足或关键检测结果未知时提示稍后重测。逐模型、逐磁盘卷评估安装空间，已校验缓存可抵扣预算。
- 常规 CPU 路径优先 Q4；确认单卡加速与资源余量后才自动推荐 Q8。保留明确的安全手动试用入口，尊重已保存选择与健康运行模型。
- 安装与冷加载前重新检查资源，GPU 失败回退 CPU 前再次核验。保持标准 **65536-token** 上下文。
- 能力检查后进行两次短合成响应采样；速度慢或证据不足时不自动启用端云协同，不删除模型或覆盖用户意图。
- 修复共享 Magpie 图标覆盖产品 favicon，管理页使用 Wefto 与 W 图标；保留原有 Wefto 更名、旧安装兼容和宿主恢复机制。
- 一键配置 skill 跟随实际 catalog/后端建议，并在需要下载安装时查询最新兼容 Release。

## 下载

提供 Windows x64、macOS arm64/x64、Linux arm64/x64 的便携包、逐文件 manifest 和 SHA256SUMS。Windows 使用同版本独立安装脚本；Unix 包含启动入口。请按平台选择完整归档，并在解压/安装前核对 SHA256。

升级前结束当前请求并停止原服务，保留配置、凭据、模型和宿主恢复记录；按项目升级指引切换程序。正常云端使用无需下载本地模型。Linux arm64 便携包不表示新增了对应的端侧推理运行时。

## 验证边界

设备资源与响应速度门槛是保守初值，不是模型官方最低配置或长上下文性能保证。本次未以真实权重完成两款量化的 64K 推理与业务质量校准。短合成检查通过也不等于判断、执行或脱敏质量已正式验收。安装包未进行发布者代码签名。
