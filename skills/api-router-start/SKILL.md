# 端云一体

面向已有 API Key、尚不熟悉端云协同的用户。默认带用户在页面中亲手操作，让用户理解关键选择和验证方法。首轮目标：接入一个常用应用，完成一次真实对话，并学会在端云协同中确认对应请求。Skill 的显示名称为“端云一体”，项目在本 skill 和使用说明中称为“端云协同”；技术调用名保留 `$api-router-start`。

用户明确选择“一键安装本地模型”或“一键端云协同”时，切换为自动执行模式，按 [一键配置](references/one-click.md) 完成操作；解释关键选择和结果，不要求用户逐步点击。端云协同允许尚未申请 API Key 的用户先完成本地准备，云端默认讯飞星辰 MaaS。

## 先确定任务和起点

从用户消息提取目标应用、供应商、模型及已经做到的步骤，只询问当前缺少的信息。目标不明确时，可问：“你准备先把哪个应用接入端云协同？你的 API Key 属于哪家平台？”不要索要实际密钥。

可以自动做只读检查，确认实际安装版本、服务、供应商是否已配置、应用连接状态，再从尚未完成的一步继续。不要仅因用户调用 skill 就自动重装、升级或重走全部教程。只解释概念的请求不启动安装流程。

Codex、Loomy、WorkBuddy 是同一服务的调用入口，不各自安装一套端云协同。跨宿主继续时，先核对程序、实际管理 URL、`dirs` 和本地模型 installed 状态；共享供应商、组和模型文件，应用自己的模型绑定分别保留。`installed: true` 且 `runtime: unloaded` 表示继续加载，不能据此重下模型或切换到另一量化版本。入口或身份冲突按 [排障与恢复](references/troubleshooting.md) 处理。

## 教学方式

- 每轮聚焦一个可完成的小步骤：用一句话解释目的，给出当前页面上的操作，说明成功后应看到什么。需要用户操作或结果时，等待反馈后继续；用户明确要求总览时可一次给全流程。
- 供应商、模型、应用绑定等概念在用到时解释。首轮从一个云端供应商、一个模型、一个应用开始；路由组、本地模型和实验性脱敏按需展开。
- 默认由用户填写凭证、选择模型、保存配置及开启应用接入。可以只读观察页面和状态；浏览器可用不代表要代替用户点击。用户明确要求代操作某一步时，在该范围内执行并解释改动，然后回到教学。
- 上述默认手动教学不适用于已选择的一键模式。调用一键模式就是授权该流程内的检测、固定来源下载、加载/能力检查、必要的本地判断与执行试用、创建路由组及目标应用接入；不重复请求同一授权。仅安装本地模型不隐含选择云端、修改路由组或接入所有应用。
- 已授权的安装/启动或代操作不重复询问确认。操作完成后，教用户在哪里找到程序、实际管理地址，以及以后怎样启动和停止。
- 用户的简短确认可作为进度线索；需要验证时检查实际结果。分别描述“服务可用”“供应商已保存”“模型列表已取得”“应用配置一致”“真实对话成功”，不要合并成一个含糊的“连接成功”。
- 不断言自己没看到的页面状态。无法直接观察时，让用户提供当前提示或脱敏后的错误信息；需要截图时提醒遮住密钥，不要求复制完整配置或日志。
- 用户中断或新开对话后，根据现有应用状态继续。只在对话中概括已确认事实、剩余步骤和下一步，不另建包含凭证或完整配置的教学进度文件。

## 版本、来源与操作约束

项目、管理界面、宿主供应商名称与使用说明统一显示“端云协同”。旧版程序可能保留旧名称，应按实际界面识别；命令、包名、发布标签、服务身份或配置路径继续使用兼容的技术标识。

- 唯一产品来源：[XHToken/magpie](https://github.com/XHToken/magpie)，发布标签 `wefto-v*`。项目展示名称为“端云协同”，既有发布包使用 `wefto` 技术标识，命令 `wefto`；旧 API-router 安装可按现有规则复用。具体多平台包与命令见安装指引。
- 每次需要下载项目包（首次安装、一键配置缺少程序、重新下载或更新到最新版），都实时查询 [XHToken/magpie Releases](https://github.com/XHToken/magpie/releases)，按发布时间选择当前系统/架构最新的兼容发布（默认包含预览版，排除草稿）。下载地址取自本次选中 Release 的 `assets[].browser_download_url`；不能写死版本号、附件 URL，或把历史示例、上次选择、缓存包当作最新。默认不传 `-Tag`/`--tag`，只有用户明确指定版本时才固定标签。查询失败应报告原因，不能退回固定旧包。普通启动仍复用现有安装；一次下载选定 Release 后，包、manifest、安装脚本和校验文件均来自该 Release，不混用中途出现的新版本。
- 先确认正在使用的版本；页面标签、功能和命令以该版本页面、帮助和标签文档为准。包对应文档形如 `https://github.com/XHToken/magpie/blob/<TAG>/README.md`。本地源码可能属于另一版本，不把其中路径直接套到已安装发行版。遇到不符先确认页面/帮助，不猜测接口或按钮。
- 通过页面已有的新手教程、供应商、应用和请求记录功能教学。只读接口仅在该版本确认存在且已验证本机实例身份后使用；不要把 POST 连接检查或获取模型误当成无网络副作用的只读查询。
- API Key 由用户在管理页面填写，聊天中只需要知道已填写或错误类型。检查时只输出存在标志和必要诊断摘要，不展示密钥、管理令牌、完整 credentials.json、请求正文或完整日志。
- 使用正常用户配置/数据根和实际返回的管理 URL。保留模型、供应商、宿主设置和恢复记录；不杀端口占用者、不删除未知锁、不重置配置或直接改宿主 JSON 来凑端点。宿主修改和恢复走当前版本支持的页面/事务。
- 首次真实云端请求前简短说明按供应商规则计费；用户已经同意测试时不重复询问。只做验证所需的小请求，不自动批量测试模型。
- 用户要接入云端应用，不意味着要启用登录自启、下载本地模型、开启实验性脱敏或修改其他应用。这些选择由用户提出后再处理。
- 一键端云协同是用户主动选择本地模型和两款目标应用的例外；仍不启用实验性脱敏、系统登录自启，不代替用户申请账号/购买额度。云端凭证缺失时保留进度、等待用户在本机页面填写后再自动继续。

## 完成与继续

用事实说明哪一段已验证。完整首轮完成后，用户应能说明所用供应商、模型和应用，并自己找到刚才的请求。可邀请用户再发送一条简短消息，独立找到对应记录；用户不想练习时尊重其选择。

结束时简述本次完成的目标、实际管理入口，以及下次如何选择模型和查看请求。若尚未跑通，明确当前阻碍、已完成部分和下一步，不把安装完成或配置保存称为全部完成。不要强制转入进阶功能。
